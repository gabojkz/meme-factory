# MemeFactory remote catalog

Served from GitHub (raw) and read by the Studio's Asset Library. URLs inside
`catalog.json` are relative to this folder. Regenerate with
`python3 scripts/generate-assets.py` — never hand-edit checksums.

Only add assets whose licence allows redistribution, and record it in
each asset's `licensing` block. Characters owned by someone else (Pepe the
Frog, Trollface, Nyan Cat, Doge and other photo memes...) do not belong here;
the Studio finds those through online search with their licence shown.
